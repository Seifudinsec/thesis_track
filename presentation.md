# ThesisTrack: Centralized Academic Management System
### *Bridging Excellence Between Students, Supervisors, and Administration*

---

## 1. The Vision & The Problem
**The Challenge:** Academic thesis management is often fragmented across emails, physical copies, and disconnected drives, leading to delayed feedback and lost progress.

**The ThesisTrack Solution:** A unified, role-based workspace designed to streamline the entire lifecycle of a thesis—from submission to final grading.

*   **Centralized:** One source of truth for all academic work.
*   **Transparent:** Real-time status tracking for students.
*   **Efficient:** Direct review loops for supervisors.

---

## 2. Architecture & Design Philosophy
**Modern Tech Stack:** Built with PHP, PDO for secure data handling, and a sleek modern UI.

**System Structure:**
*   **Core Logic:** Centralized session and database management (config/db.php).
*   **Dynamic UI:** Responsive sidebar navigation with role-aware layouts.
*   **Security:** Password hashing, session-based access control, and IDOR prevention.

**Color Palette:**
*   **Primary (#4A70A9):** Professional academic blue.
*   **Secondary/Accent (#8FABD4):** Soft trust-building tones.
*   **Background (#EFECE3):** Clean, focused workspace aesthetic.

---

## 3. Role-Based Ecosystem
Tailored experiences for every user level:

*   **Students:** Dashboard for tracking progress, simple PDF uploads, and instant feedback viewing.
*   **Supervisors:** A dedicated review queue to evaluate work, assign grades, and provide detailed commentary.
*   **Admins:** Full oversight of system health, user lifecycle management, and global submission monitoring.

---

## 4. Technical Excellence & Cleanup
*The "Behind the Scenes" of our recent refactor:*

*   **Dynamic Routing:** Eliminated hardcoded paths for universal deployment.
*   **Optimization:** Removed redundant assets and consolidated session starts to reduce server overhead.
*   **Code Integrity:** Standardized include patterns and sanitized code for maximum readability and maintainability.
*   **Robustness:** Automated cleanup of legacy data and unused assets.

---

## 5. Future Roadmap & Scalability
ThesisTrack is built to grow:

*   **AI Integration:** Automated plagiarism checks and initial formatting reviews.
*   **Real-time Collaboration:** Live chat between students and supervisors.
*   **Advanced Analytics:** Data-driven insights for lecturers to identify students needing additional support.
*   **Modular Extensions:** Ready for API integration with University SIS (Student Information Systems).
